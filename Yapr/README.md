# Yapr (iOS)

Yapr is the iOS companion to the macOS Clicky app. It lives on your phone, listens through a press-and-hold blue orb, sees your most recent screenshot from your Photos library, asks Claude what to say, and answers out loud through ElevenLabs. A Control Center tile lets you ask about your most recent screenshot in one tap.

The voice + Claude + ElevenLabs + AssemblyAI engine is a port of the open-source Clicky engine in `../leanring-buddy/`, used and adapted under the MIT license.

> Status: v1 scaffold. Built fresh for "Path 1": Control Center tile + Photos-library screenshots + voice orb. No background screen capture (App Store-friendly), no broadcast extension yet.

## First-time setup

### 0. Prerequisites

- macOS with Xcode 16 (or later) installed at `/Applications/Xcode.app`.
- A Cloudflare Worker deployed from `../worker/` with the same secrets the macOS app uses (`ANTHROPIC_API_KEY`, `ASSEMBLYAI_API_KEY`, `ELEVENLABS_API_KEY`). See `../README.md` and `../worker/README.md`.
- An Apple Developer account (free or paid) for code signing — the free tier is enough to run on your own device.

If `xcodebuild` ever complains about license terms, accept them once:

```bash
sudo xcodebuild -license accept
```

If `xcode-select -p` points at `/Library/Developer/CommandLineTools` instead of Xcode, point it at Xcode so SwiftPM and other tools use the up-to-date toolchain:

```bash
sudo xcode-select -switch /Applications/Xcode.app/Contents/Developer
```

### 1. Install XcodeGen

The Xcode project (`Yapr.xcodeproj/`) is generated from `project.yml` by [XcodeGen](https://github.com/yonaskolb/XcodeGen) so changes to targets, build settings, plists, and entitlements live in a single readable YAML file rather than the binary `.pbxproj`.

```bash
brew install xcodegen
```

### 2. Set your bundle ID prefix (one-time)

The default prefix is `com.tobi`. To use your own Apple Developer team, search-replace `com.tobi` with your prefix in **two** places — they must stay in sync:

- `Yapr/project.yml`
- `Yapr/Shared/AppGroupKeys.swift` (the `identifier = "group.com.tobi.yapr"` line)

### 3. Set your Cloudflare Worker URL

Open `ClickyShared/Sources/ClickyShared/WorkerConfiguration.swift` and replace the placeholder:

```swift
public static let workerBaseURL: String = "https://your-worker-name.your-subdomain.workers.dev"
```

with your deployed Worker base URL. The same Worker is used by both the macOS Clicky app and Yapr.

### 4. Generate the Xcode project

```bash
cd Yapr
xcodegen generate
```

This regenerates `Yapr.xcodeproj/`, `App/Info.plist`, `App/Yapr.entitlements`, `ControlWidget/Info.plist`, and `ControlWidget/YaprControl.entitlements` from `project.yml`. Re-run any time you change `project.yml`.

### 5. Open in Xcode and configure signing

```bash
open Yapr/Yapr.xcodeproj
```

In Xcode:

1. Select the project in the navigator → **Yapr** target → **Signing & Capabilities**. Pick your Team. Repeat for the **YaprControl** target.
2. Both targets need the **App Groups** capability with `group.com.tobi.yapr` (or your renamed equivalent). xcodegen wires this up automatically; if Xcode complains, open Signing & Capabilities and let it auto-fix.
3. Pick a simulator (iPhone 16 / iOS 18+) or your physical iPhone, and `Cmd+R` to build & run.

### 6. First launch

The first time you run Yapr, it asks for two permissions:

- **Microphone** — required so push-to-talk can capture your voice.
- **Photos library** — required so Yapr can read your most recent screenshot. Yapr never writes, edits, or saves photos.

Once both are granted, you'll see your most recent screenshot in the preview and a blue voice orb at the bottom. **Press and hold the orb, ask anything about the screenshot, and release** — Yapr transcribes via AssemblyAI, asks Claude, and answers out loud via ElevenLabs.

### 7. Add the Control Center tile

After the app is installed, swipe down from the top-right of your iPhone to open Control Center. Tap **Edit** → **Add a Control** → search for **Ask Yapr**. Tap it to add the tile. From now on, the flow is:

1. Take a normal iPhone screenshot (Side button + Volume Up).
2. Pull down Control Center.
3. Tap the Yapr tile — the app launches straight into ask mode.
4. Hold the orb, ask, release.

(iOS sandboxing does not allow a Control Center button to capture the screen silently in the background — only an active broadcast session can do that, and broadcasts always show a recording UI. Going through Photos is the friction-light flow that stays App Store-friendly.)

## Editing the project structure

Because the `.xcodeproj` is generated, **do not edit it by hand** — your changes will be wiped on the next `xcodegen generate`.

To add a new source file: drop it in `Yapr/App/` (or `Yapr/ControlWidget/`, or `Yapr/Shared/`), then run `xcodegen generate`. xcodegen picks files up from the `sources:` paths in `project.yml`.

To add a new entitlement, plist key, build setting, or capability: edit `Yapr/project.yml`, then `xcodegen generate`.

To add a new external Swift Package: add it under `packages:` in `project.yml`, list it under the relevant target's `dependencies:`, then `xcodegen generate`.

## Architecture notes

- **State machine.** `YaprViewModel` (`@MainActor`) owns the entire push-to-talk pipeline: `idle → listening → processing → responding → idle`. Held-down orb starts a streaming AssemblyAI websocket; released orb sends the final transcript + most-recent screenshot to Claude; the response (with `[POINT:...]` tag stripped) plays through ElevenLabs and a pulsing dot lands on the screenshot at the parsed coordinate.
- **Push-to-talk gesture.** A zero-distance `DragGesture`, not `LongPressGesture` — the latter has an unavoidable activation delay that makes the orb feel laggy.
- **Audio session.** Configured once at launch (`AVAudioSessionConfigurator`) with `.playAndRecord`/`.voiceChat`/`.defaultToSpeaker` so mic input and TTS playback both work, on speaker by default, ducking other audio while Yapr speaks.
- **Photos.** `RecentScreenshotProvider` uses `PHFetchOptions` with `mediaSubtypes & .photoScreenshot != 0` and `fetchLimit = 1` to read only the user's single most-recent screenshot. The image is downscaled to a 1280px long edge before being base64-encoded for Claude.
- **Control Center tile.** `YaprAskControl` (`ControlWidget` + `StaticControlConfiguration`) calls `AskYaprIntent` (an `AppIntent` with `openAppWhenRun = true`). The intent writes a "did launch from Control Center" flag in App Group `UserDefaults`; the app reads + clears it on launch and refreshes the screenshot immediately.
- **Worker proxy.** Same Cloudflare Worker as the macOS app. The iOS app never holds the real Anthropic / AssemblyAI / ElevenLabs keys — only the Worker URL and short-lived AssemblyAI temp tokens.

## Deferred for later versions

These were intentionally left out of v1 to keep App Store review fast and the surface area small:

- Settings screen (model picker, voice selection, history list).
- Persistent conversation history across launches (currently in-memory only).
- PostHog analytics integration (the macOS app uses PostHog; iOS v1 ships analytics-free).
- Live Activities, lock-screen widgets, Home-Screen widgets.
- ReplayKit Broadcast Extension for true cross-app screen capture.
- App Icon (the asset slot is empty — drop a 1024×1024 PNG into `Assets.xcassets/AppIcon.appiconset/`).
